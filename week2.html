HTML 구조

HTML은 웹 페이지의 내용을 구조에 맞게 배치하는 역할을 합니다.

제목과 문단

h1부터 h6까지 제목을 표현할 수 있으며 p 태그는 문단을 나타냅니다.

목록과 링크

ul, ol, li 태그로 목록을 만들고 a 태그로 다른 페이지에 연결합니다.

입력과 영역

form, label, input을 이용해 사용자가 정보를 입력할 수 있습니다.

정보를 구성하는 순서

  • 정보 이해
  • 주요 기능 확인
  • 이용 방법 확인
  • 소식 받기

HTML 작성 시 확인할 내용

  1. 페이지의 주제를 제목으로 작성합니다.
  2. 관련 있는 내용을 영역별로 나눕니다.
  3. 입력 요소에는 알아보기 쉬운 설명을 붙입니다.

Live Server

Live Server는 작성한 HTML과 CSS를 브라우저에서 확인할 수 있도록 도와주는 도구입니다.

코드를 수정한 뒤 브라우저 화면이 변경되는지 확인하면서 작업할 수 있습니다.

주요 기능

탭을 선택하면 해당 주제의 내용을 확인할 수 있습니다.

HTML

HTML은 제목, 문단, 목록, 링크, 입력창 등 웹 페이지의 구조를 만듭니다.

CSS

CSS는 색상, 글꼴, 여백, 배치, 반응형 화면 등 웹 페이지의 디자인을 담당합니다.

JavaScript

JavaScript는 버튼 클릭, 입력값 확인, 화면 변경과 같은 동작을 처리합니다.

노트 작성

제목과 내용을 입력한 뒤 저장합니다. 제목은 최대 15자, 내용은 최대 2,000자까지 입력할 수 있습니다.
