서비스 소개

하루노트는 공부한 내용이나 기억하고 싶은 정보를 간단하게 작성하고 보관하는 노트형 학습 기록 서비스입니다. 복잡한 문서 대신 제목과 메모를 입력해 학습 내용을 정리하고, 필요할 때 저장된 기록을 다시 확인할 수 있습니다.

사용자

공부한 내용이나 중요한 정보를 간단하게 기록하고 싶은 학생 및 학습자

서비스 목적

주요 기능

학습 기록 작성

제목과 메모를 입력해 공부한 내용을 정리합니다.

노트 저장 및 확인

작성한 노트를 저장하고 메인 페이지에서 다시 확인합니다.

기록 관리

필요에 따라 작성 내용을 초기화하고 학습 체크리스트로 진행 상황을 확인합니다.

이용 방법

하루노트는 노트 작성부터 저장까지 순서대로 진행할 수 있습니다.

  1. 시작

    메인 페이지에서 노트 쓰기를 눌러 노트 작성 페이지로 이동합니다.

  2. 입력 및 수정

    노트 제목과 메모 내용을 입력합니다. 제목을 수정하면 화면의 제목에도 바로 반영됩니다.

  3. 내용 확인

    입력한 제목과 메모를 확인하고, 잘못된 내용은 수정합니다.

  4. 저장 완료

    필수 입력 항목을 확인한 후 저장합니다. 저장이 완료되면 화면에 완료 메시지가 표시됩니다.
