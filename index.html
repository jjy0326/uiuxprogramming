HTML 요소와 구조

제목과 문단으로 정보를 정하고, 영역과 링크로 이동합니다.

h1~h3는 제목의 단계와 순서를 통해 정보의 중요도와 포함 관계를 파악합니다.

img는 웹페이지에 이미지를 보여주는 요소입니다.

nav는 영역을 이해하고 다른 페이지나 영역으로 이동할 수 있게 합니다.

  • h1: 가장 큰 제목
  • h2: 주요 내용 제목
  • h3: 세부 내용 제목
  • p: 문단이나 설명
  • img: 이미지 표시
  • ul: 순서 없는 목록
  • ol: 순서 있는 목록
  • li: 목록의 하나의 항목
  • nav: 다른 곳으로 이동하는 메뉴
  • form: 사용자 입력을 받는 곳
  • header: 페이지의 머리말 영역
  • main: 페이지의 주요 내용 영역
  • section: 내용을 주제별로 나누는 영역
  • footer: 페이지의 하단 영역

Live Server 역할

코드를 저장하면 변경된 결과를 브라우저에서 실시간으로 확인할 수 있게 해줍니다.

입력과 사용자 행동

label은 클릭하면 입력칸을 활성화하고 보조기술이 입력 항목을 이해하도록 도와줍니다.

input은 타입을 알맞게 설정하여 입력과 제출 및 검증에 활용합니다.
