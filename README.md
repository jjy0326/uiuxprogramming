입력창과 버튼을 한 줄로 사용하기 어려웠다.

## 수정한 내용

- header, main, footer에 width와 max-width를 적용했다.
- 기능 카드 목록을 Grid로 변경하고 자동으로 열이 조정되도록 수정했다.

# 5주차 JavaScript 기능 추가 기록

## 추가한 기능

제목 입력창에 입력한 내용으로 페이지 제목을 변경하는 기능을 추가했다.

## 수정한 내용

- JavaScript를 사용해 제목 입력값을 가져오도록 수정했다.
- 입력한 제목이 비어 있는지 확인하도록 조건문을 추가했다.
- 저장 버튼을 누르면 입력한 제목으로 h1 제목이 변경되도록 구현했다.
- 브라우저 탭의 제목도 함께 변경되도록 수정했다.
- 변경된 제목을 localStorage에 저장해 새로고침 후에도 유지되도록 구현했다.
- 초기화 버튼을 눌러 제목을 원래대로 되돌릴 수 있도록 추가했다.

## 달라진 점

제목을 입력하고 저장 버튼을 누르면 페이지의 h1 제목과 브라우저 탭 제목이 변경된다. 새로고침 후에도 변경된 제목이 유지되며, 초기화 버튼으로 원래 제목으로 되돌릴 수 있다.

## 9회차 주 입력 폼 개선 내용

### 1. 추가·수정한 기능

- 하루노트의 `newnote.html`에 새 노트 작성 폼을 구성했습니다.
- 노트 제목, 수업 주제 선택, 학습 항목 제목과 내용을 입력할 수 있도록 했습니다.
- 수업 주제에서 `기타`를 선택하면 직접 입력 칸이 나타나며, 다른 주제를 선택하면 입력 칸이 숨겨집니다.
- 숨겨진 직접 입력 칸은 `disabled` 처리하여 입력 및 제출 대상에서 제외했습니다.
- 학습 항목을 추가하거나 삭제할 수 있으며, 항목은 최소 1개, 최대 30개까지 작성할 수 있습니다.
- 입력한 노트를 브라우저의 `localStorage`에 저장하고 메인 페이지의 저장된 노트 목록에서 확인할 수 있습니다.
- 입력 내용을 미리보기로 확인하는 기능을 유지했습니다.

### 2. 입력 조건 및 안내

| 입력 항목 | 입력 조건 |
| 노트 제목 | 필수, 2~60자 |
| 수업 주제 | 필수, 선택 목록에서 선택 |
| 직접 입력할 주제 | `기타` 선택 시 필수, 2~60자 |
| 항목 제목 | 필수, 항목별 2~80자 |
| 항목 내용 | 필수, 항목별 10~1,000자 |

입력 중 제목과 항목별 글자 수를 표시합니다. 입력 조건에 맞지 않으면 해당 입력란 아래에 오류 문구와 수정 방법을 표시하고, 내용을 수정하면 오류 표시를 해제합니다.

### 3. 제출 및 결과 처리

- 폼의 `submit` 이벤트에서 입력값을 검사합니다.
- 입력 조건을 충족하지 못하면 저장을 중단하고 첫 번째 오류 항목으로 포커스를 이동합니다.
- 저장 중에는 진행 문구를 표시하고 저장 버튼을 비활성화하여 중복 제출을 방지합니다.
- 저장에 성공하면 완료 문구를 표시하고 입력 폼을 초기화합니다.
- 브라우저 저장에 실패하면 오류 문구를 표시하며 입력 내용은 유지하여 다시 시도할 수 있도록 했습니다.
- 서버 연동 없이 브라우저 `localStorage`를 사용합니다.

### 4. 수정한 파일

- `index.html`: 잘못된 닫는 태그를 정리했습니다.
- `newnote.html`: 주제 선택, 조건부 직접 입력, 입력 도움말, 글자 수 및 오류 표시 영역을 추가했습니다.
- `newnote.js`: 조건부 입력, 실시간 입력 상태, 유효성 검사, 저장 중 상태, 저장 성공·실패 처리 및 미리보기 동작을 정리했습니다.
- `script.js`: 페이지마다 존재하는 요소가 다르므로 요소가 있을 때만 이벤트를 연결하도록 수정하고, 새 노트와 기존 2주차 노트를 메인 페이지에서 표시하도록 정리했습니다.
- `style-additions.css`: 입력 도움말, 오류, 저장 상태, 조건부 입력 및 모바일 화면 스타일을 추가했습니다.

### 5. 브라우저 확인 순서

1. 제목과 항목 내용을 비워 둔 상태에서 저장하여 필수 입력 오류가 표시되는지 확인합니다.
2. 제목을 1자만 입력하고, 항목 내용도 10자 미만으로 입력하여 최소 글자 수 오류가 표시되는지 확인합니다.
3. 오류가 표시된 입력값을 올바르게 수정했을 때 오류 문구가 해제되는지 확인합니다.
4. 수업 주제를 `기타`로 선택하면 직접 입력 영역이 나타나고, 다른 주제로 변경하면 숨겨지면서 비활성화되는지 확인합니다.
5. 모든 입력 조건을 충족한 뒤 저장하여 저장 중 문구와 버튼 비활성화, 저장 완료 문구를 확인합니다.
6. 메인 페이지로 이동해 저장한 노트가 목록에 표시되는지 확인합니다.
7. 다시 작성 기능을 눌렀을 때 입력값, 오류 문구, 글자 수 및 버튼 상태가 초기화되는지 확인합니다.

### 6. 실패 처리 및 코드 위치

- 필수 입력 및 글자 수 검증: `newnote.js`의 `validateForm()`
