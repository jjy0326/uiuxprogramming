# 4주차 반응형 수정 기록

## 확인한 문제

390px에서 메뉴와 기능 카드, 폼이 좁아지고
입력창과 버튼을 한 줄로 사용하기 어려웠다.

## 수정한 내용

- header, main, footer에 width와 max-width를 적용했다.
- 기능 카드 목록을 Grid로 변경하고 자동으로 열이 조정되도록 수정했다.
- 768px 이하에서 메뉴와 기능 카드를 한 열로 변경했다.
- 768px 이하에서 폼을 세로로 변경하고 입력창과 버튼을 화면에 맞게 수정했다.
- 768px 이하에서 흐름 목록도 세로로 변경하고 화살표 방향을 아래쪽으로 변경했다.

## 달라진 점

390px에서도 메뉴, 카드, 폼이 화면 안에서 한 열로 표시되고
가로 스크롤 없이 사용할 수 있다.

## 확인할 화면 너비

1100px / 769px / 768px / 390px

# 5주차 JavaScript 기능 추가 기록

## 추가한 기능

제목 입력창에 입력한 내용으로 페이지 제목을 변경하는 기능을 추가했다.

## 수정한 내용

- JavaScript를 사용해 제목 입력값을 가져오도록 수정했다.
- 입력한 제목이 비어 있는지 확인하도록 조건문을 추가했다.
- 저장 버튼을 누르면 입력한 제목으로 h1 제목이 변경되도록 구현했다.
- 브라우저 탭의 제목도 함께 변경되도록 수정했다.
- 변경된 제목을 localStorage에 저장해 새로고침 후에도 유지되도록 구현했다.
- 초기화 버튼을 눌러 제목을 원래대로 되돌릴 수 있도록 추가했다.

## 달라진 점

제목을 입력하고 저장 버튼을 누르면 페이지의 h1 제목과 브라우저 탭 제목이 변경된다. 새로고침 후에도 변경된 제목이 유지되며, 초기화 버튼으로 원래 제목으로 되돌릴 수 있다.

## 확인할 기능

제목 입력 / 제목 변경 / 새로고침 후 제목 유지 / 제목 초기화

6주차 JavaScript 기능 확장 기록

추가한 기능

학습 메모, 학습 체크리스트, 기능 탭, 노트 저장 기능을 추가하고 JavaScript로 동작하도록 구현했다.

수정한 내용

JavaScript를 사용해 다크 모드 전환 기능을 추가했다.

메모 입력 내용을 localStorage에 저장해 새로고침 후에도 유지되도록 구현했다.

학습 체크리스트의 완료 항목 수와 진행 상태를 표시하도록 수정했다.

HTML, CSS, JavaScript 탭을 눌러 해당 내용을 확인할 수 있도록 구현했다.

노트의 제목과 내용을 입력하고 저장, 수정, 삭제할 수 있도록 구현했다.

저장한 노트와 화면 설정을 localStorage에 저장해 새로고침 후에도 유지되도록 수정했다.

노트 제목은 1자 이상 15자 이하로 입력하도록 제한하고, 입력값을 확인하는 조건문을 추가했다.

사용하지 않는 이벤트 처리 실습 영역과 관련 코드를 제거했다.

달라진 점

다크 모드, 메모, 학습 체크리스트, 기능 탭, 노트 관리 기능을 사용할 수 있다. 입력한 메모와 저장한 노트, 화면 설정이 새로고침 후에도 유지되며, 노트를 직접 수정하거나 삭제할 수 있다.

## 7주차 중 기존 부족한 부분 수정 내용

- 제목 입력이 비어 있을 경우 `alert()`와 `saveMessage`에 오류 안내를 표시하도록 수정
- 노트 저장 및 수정 결과에 따라 완료 메시지가 구분되도록 수정
- 초기화 버튼 문구를 `저장한 제목 삭제 및 초기화`로 변경
- 초기화 버튼을 누르면 `localStorage`에 저장된 제목을 삭제하고 페이지 제목과 브라우저 탭 제목을 기본 제목으로 복원하도록 수정
- 초기화 결과와 저장 오류를 화면 안내 문구로 확인할 수 있도록 수정


### 1. 기존 코드에서 변경한 내용

기존에는 `index.html` 한 페이지에 HTML 구조 설명, Live Server 설명, HTML·CSS·JavaScript 탭, 노트 작성 폼, 저장된 노트 목록이 모두 포함되어 있었습니다.

이번 작업에서는 기능을 목적에 따라 분리하여 메인 페이지와 노트 작성 페이지로 구성했습니다.

- **index.html**
  - 페이지 제목을 기존 `UX/UI 2주차 수업 내용과 정리`에서 `하루노트`로 변경했습니다.
  - 서비스 소개, 주요 기능, 이용 방법을 추가했습니다.
  - 주요 사용자, 서비스 목적, 핵심 행동을 카드 형태로 정리했습니다.
  - 기존 학습 체크리스트, 테마 변경 버튼, 간단 메모 기능을 유지했습니다.
  - 저장된 노트를 확인하는 영역을 메인 페이지에 배치했습니다.
  - 노트 작성 페이지로 이동할 수 있도록 링크를 추가했습니다.

- **week2.html**
  - 기존 `index.html`에 있던 HTML 구조, Live Server, 주요 기능 관련 수업 정리 내용을 분리했습니다.
  - 노트 작성 기능을 이 페이지에서 이용하도록 구성합니다.
  - 메인 페이지로 돌아갈 수 있는 링크를 제공합니다.

- **style.css**
  - 기존 노란색 노트 디자인과 반응형 스타일을 공통으로 사용합니다.
  - 페이지를 분리하더라도 전체적인 디자인이 일관되게 유지되도록 합니다.

- **script.js 및 노트 저장 기능**
  - 기존 코드의 테마 변경, 간단 메모 저장, 학습 체크리스트, 노트 저장 및 수정·삭제 기능을 페이지별 역할에 맞게 분리합니다.
  - `localStorage`를 이용해 저장된 노트를 페이지 간에 공유할 수 있도록 구성합니다.

### 2. 사용자 이용 흐름

1. 메인 페이지에서 하루노트의 서비스 소개와 주요 기능을 확인합니다.
2. 2주차 수업 정리 및 노트 작성 페이지로 이동합니다.
3. 노트 제목과 메모 내용을 입력합니다.
4. 입력한 내용을 확인한 뒤 노트를 저장합니다.
5. 메인 페이지로 돌아와 저장된 노트를 확인합니다.

### 3. 변경 목적

기존에는 수업 정리 내용과 노트 작성 기능이 한 페이지에 함께 있어 각 기능의 목적이 명확하게 구분되지 않았습니다. 이를 메인 페이지와 노트 작성 페이지로 나누어 사용자가 서비스의 목적을 먼저 이해하고, 필요한 기능으로 이동할 수 있도록 변경했습니다.

또한 메인 페이지에서 저장된 기록을 확인할 수 있도록 구성해 노트를 작성하는 과정과 저장한 내용을 다시 확인하는 과정을 구분했습니다.

### 4. 확인할 사항

- 메인 페이지에서 노트 작성 페이지로 정상적으로 이동하는지 확인합니다.
- 노트 작성 후 저장한 기록이 메인 페이지에 표시되는지 확인합니다.
- 노트 수정 및 삭제 기능이 정상적으로 작동하는지 확인합니다.
- 테마 변경, 간단 메모, 학습 체크리스트 기능이 유지되는지 확인합니다.
- 모바일 화면에서도 페이지와 입력 영역이 정상적으로 표시되는지 확인합니다.
